- P0：管理员查看开户企业名称并维护 Logo；访客在登录页确认所访问企业。

- 未配置或恢复默认 Logo 后，H5 使用现有“访”字标。
- 保存后刷新租户后台和打开统一企业 H5，三项配置仍能正确显示。
- H5 在 390×844、430×932 下无横向溢出，登录主操作可正常使用。
