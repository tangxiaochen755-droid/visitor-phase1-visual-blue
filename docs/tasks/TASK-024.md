# TASK-024 — 修正统一 H5 注册身份选择

## 范围

- 将统一企业 H5 注册页改为由用户显式选择“访客”或“员工”。
- 根据注册身份动态展示访客或员工字段，不再由页面 URL 预先写死注册身份。
- 员工注册关闭时仅允许访客注册，不展示员工选项。
- 补齐员工注册待审核、审核拒绝用户再次登录 H5 时的状态页和后续动作。
- 同步产品决策、功能映射、测试清单和变更记录。

## 排除项

- 不改变登录后的访客与被访人业务功能。
- 不改变两类注册字段、员工审核规则和访客代申请补绑规则。
- 不推送、不发布。

## 验收标准

- 员工注册开放时，注册页首项展示访客/员工身份选择。
- 访客字段为姓名、单位名称（选填）、手机号、验证码、密码和确认密码。
- 员工字段为员工姓名、所属部门（手工填写）、手机号、验证码、密码和确认密码。
- 切换身份后说明、字段和提交按钮同步变化。
- 员工注册关闭时访客注册仍可进入，且不展示员工身份选项。
- 待审核员工登录后不得进入业务页；审核拒绝员工登录后展示拒绝原因并可修改资料重新提交。

- 员工注册关闭时已验证仅展示访客注册字段，不展示员工身份选项。
