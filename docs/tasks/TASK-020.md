# TASK-020 — 补齐企业前台注册流程

> 后续员工注册字段、入口名称和状态口径已由 `TASK-023` 更新；本文件保留当时任务范围与验收历史，不再作为当前员工注册字段基线。

## 范围

- 在统一企业前台登录页增加访客注册和被访人注册入口。
- 访客通过姓名、手机号、验证码和密码自主注册，单位选填；注册后按当前租户及手机号自动补绑待绑定代申请。
- 被访人可在当前企业 H5 提交员工/被访人注册申请，通过姓名、所属部门、工号、手机号、验证码和密码完成登记；默认进入待认证并由企业管理员审核，与后台批量配置、单个添加并行。
- 访客注册始终开放；超级管理端按租户配置是否开放员工 H5 自注册，默认关闭，开户后可调整。
- 租户后台账号增加独立“注册审核权限”，拥有权限的账号可在员工管理中审核自注册申请。
- 补充接口契约、联调验收、测试清单和长期业务决策。

## 排除项

- 不改变角色互斥、租户隔离、登录方式配置和历史记录归属规则。
- 不发布，除非用户另行确认。

## 验收标准

- 访客与被访人入口均可从登录页进入并返回；访客注册后进入业务页，被访人自注册后进入待审核结果页。
- 手机号、验证码、必填身份字段、密码长度、二次密码及协议均有校验。
- 390×844、430×932 下无横向溢出，注册长表单允许自然纵向滚动。
- 访客注册成功进入正确角色首页并反馈代申请已关联；被访人提交后不得进入业务首页，需展示待企业审核状态。
- 员工自注册关闭时 H5 不展示被访人注册入口；开放时可提交。注册审核按钮只对拥有独立权限的后台账号开放。

## 状态

- 已完成。
- 已按 SaaS 租户开关与独立审核权限扩展完成。

## 验收证据

- 访客完成注册并进入“申请访问”首页，反馈“注册成功，历史代申请已自动关联”。
- 被访人完成自主注册后停留在认证结果页，展示“等待企业审核”，审核通过前不进入被访人业务首页。
- 超级管理端关闭华辰租户员工自注册后，列表即时回显“关闭”；被访人 H5 不再展示注册入口，访客 H5 仍展示“访客注册”。恢复开放后列表即时回显“开放”。
- 企业后台以无注册审核权限入口进入员工管理时，待审核记录仅有“查看”；有权限时展示“审核”，审核通过后生成 `EMP-000005`、账号状态变为“启用”，并反馈短信通知结果。
- 390×844 与 430×932 下文档和注册容器宽度一致，无横向溢出；长表单自然纵向滚动。
- 浏览器控制台无 error 或 warning。
