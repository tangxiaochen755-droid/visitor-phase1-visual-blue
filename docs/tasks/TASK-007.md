- 日期：2026-08-14
- 负责人：Codex
- 基线：`f0be5b3`

## 范围

- 后台预约时段同时用于单次和长期拜访；长期拜访前台支持选择多个已启用时段。
- 来访日期、来访时段、被访人固定为显示且必填。
- 申请拆分为审核状态与来访状态，后台申请列表分别展示和筛选。
- 来访码、出访码展示生效期和有效期限。
- 前台筛选“日期范围”改为“来访日期范围”，来访状态作为次筛选进入 Bottom Sheet。
- 场所设备增加设备类型（扫码设备、扫码中台），新增时允许暂不绑定场所与通行点，后续编辑绑定。
- 同步原型与研发交付文档。

## 状态口径

- 审核状态：待审核、审核通过、审核拒绝。
- 来访状态：待来访、来访中、已过期、来访结束、已终止。
- 待审核或审核拒绝时来访状态尚未产生，界面显示“—”，不新增第三类业务状态。
- 长期拜访审核通过且当前无在场批次时展示“待来访”；每次扫码进入后展示“来访中”，离开后恢复“待来访”；授权期结束为“已过期”。

## 验收标准

- 长期拜访至少可勾选一个时段并支持多选，未选择时不能提交。
- 来访日期/有效期、时段、被访人均有必填标识与提交校验。
- 前后台列表和详情分别展示审核状态、来访状态。
- 后台申请列表具备两个独立状态筛选字段。
- 通行码页明确显示生效期和有效期限。
- 新增扫码设备/扫码中台可保存“未绑定”场所和通行点，并可再次编辑绑定。
- 移动端 390×844、430×932 与后台 1366×768、1440×900 无非预期横向溢出。

## 验证结果

- 企业前台：430×932 验证长期拜访显示 4 个时段、默认勾选 2 个；列表显示双状态且详情无旧“当前状态”。
- 租户后台：1440×900 验证申请表含“审核状态”“来访状态”独立列，详情含授权生效期与当前码有效期限。
- 场所设备：验证扫码中台可在场所、通行点均未绑定时创建，保存数据为“未绑定”。
- 浏览器控制台：企业前台与租户后台均无 JavaScript 错误。

## 排除项

- 不新增审批层级、门禁硬件协议和设备通信实现。
- 不定义二维码签名、刷新频率等研发实现方案。
