# TASK-010 — 短信渠道改为开户后独立配置

- 状态：已完成（已发布）
- 日期：2026-08-14
- 基线：`bfdfb50`
- 线上功能提交：`b9b680b`

## 范围

- 新增租户开户时不再选择短信发送方式，开户后默认使用平台短信渠道。
- 租户列表增加独立“短信配置”操作，可在平台默认渠道和自有企信通之间切换。
- 切换为自有企信通时配置 `AppKey`、`AppSecret`；既有密钥不明文回显。
- 生成待审核提醒、审核通过通知、审核拒绝通知 3 条默认短信模板，并允许修改模板内容。

## 排除项

- 不修改开户、登录、审核、来访和通行业务流程。
- 不接入真实短信供应商接口，不保存或传输真实密钥。
- 不虚构企信通接口地址、签名方式、模板 ID 和回执字段。

## 待确认

- “企信通”不是统一接口标准。当前原型按需求暂用 `AppKey`、`AppSecret`；研发接入前必须根据最终采购供应商文档冻结实际凭证字段。

## 验收标准

- 新增租户弹窗不出现短信发送方式，且明确开户后默认使用平台渠道。
- 每个已开户租户均有“短信配置”入口。
- 平台渠道不显示密钥字段；选择自有企信通后显示 `AppKey`、`AppSecret` 且新配置必填。
- 短信配置包含 3 条非空默认模板，内容可编辑；密钥和模板校验有效。
- 1366×768、1440×900 无页面横向溢出，弹窗可滚动且无 JavaScript 错误。

## 验证结果

- 内联 JavaScript 语法解析通过。
- 1366×768：开户弹窗无短信方式字段；短信配置入口可打开，平台渠道隐藏密钥；切换企信通后缺少密钥会阻止保存。
- 1440×900：企信通已有配置不回显密钥，3 条模板完整可编辑；页面无横向溢出，控制台无错误。
- GitHub Pages 构建成功；线上 `super-admin.html` 返回 HTTP 200，文件 SHA-256 与本地完全一致。
