# 变更日志

## 2026-09-15 · TASK-020 企业前台注册流程

- 统一企业前台新增访客注册入口，支持姓名、单位（选填）、手机号验证码、密码及协议校验，注册后关联同手机号待绑定代申请。
- 新增被访人自主注册入口，通过员工姓名、所属部门、工号、手机号验证码和密码提交当前租户员工认证；默认由企业管理员审核，审核前不授予被访人业务权限；后台批量配置、单个添加继续直接建档。
- 固化多租户 SaaS 标品边界：平台提供统一安全下限和默认闭环，企业差异由租户配置承接，客户专属逻辑不得污染标品主流程。
- 访客注册固定开放；超级管理端新增租户级“员工自注册”开关，关闭时被访人 H5 隐藏注册入口。
- 租户后台账号新增独立“注册审核权限”，员工管理增加待审核记录及通过、拒绝流程。
- 同步注册接口建议、联调验收、产品范围映射与角色互斥约束。
