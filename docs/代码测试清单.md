# 访客系统一期代码测试清单

版本：V1.1
整理日期：2026-09-11
适用范围：超级管理后台、租户管理后台、统一企业前台及对应后端服务；扫码设备端暂缓
业务依据：`一期功能范围与前台映射.md`、`docs/DECISIONS.md`、`docs/integration/`、`docs/研发交付简版.md`

## 1. 使用说明

- 结果填写：`通过 / 失败 / 阻塞 / 不适用`，失败项需关联缺陷编号、截图、请求与 `requestId`。
- 优先级：P0 为核心闭环或安全边界，P1 为主要功能与异常，P2 为兼容性和体验。
- 测试层次：FE 为前端，BE 为后端，E2E 为前后台联调闭环。
- 当前唯一企业前台入口为 `frontends/enterprise-h5.html`；历史 `visitor-h5.html`、`visitee-h5.html` 不纳入测试。
- 本轮暂不执行扫码设备端页面、设备绑定及设备核验专项用例；相关清单保留在第 8 节，后续恢复时直接启用。申请、访问记录及服务端状态机的数据一致性测试仍在本轮范围内。
- `FUTURE-01` 至 `FUTURE-07`、短信自动重试、二维码离线策略和代申请二次审批未冻结，不作为当前版本缺陷判定依据。
- 高保真页面不得展示研发说明、后台机制、接口规则或完整异常枚举；仅保留真实用户需要的操作、状态、校验、风险及恢复文案。
- 资料优先级：当前浅蓝页面与 `docs/DECISIONS.md` > 当前仓库范围/联调文档 > 仓库外早期标品清单与产品说明书 > 历史黑白原型、备份和交接副本。低优先级资料与高优先级基线冲突时不得并入当前测试范围。
- 流程版本统一以 `docs/最新产品逻辑测试基线.md` 为入口；除验证当前正向闭环外，必须执行第 13 节的旧流程回归禁用项。
