## 使用原则

1. 业务状态、角色边界和数据关系以本包与 `docs/DECISIONS.md` 为评审基线。
2. `04-接口契约建议稿.md` 中 URL、HTTP 方法和响应结构属于联调建议，须由前后端评审确认后冻结。
3. 所有业务接口都必须由服务端校验租户、角色、数据范围和当前状态；前端隐藏按钮不能替代权限校验。
4. 申请记录和通行事件是两类数据：一个申请可以关联多条进入/离开事件，不允许相互覆盖。
5. 一期无“门卫人员账号”。扫码端使用唯一设备编码绑定，只负责核验和写入通行事件。

## 联调冻结物

评审通过后，建议共同冻结以下内容并记录版本号：

- 角色代码、权限点代码和数据范围算法；
- 状态枚举、状态转换条件和显示文案；
- OpenAPI/Apifox 接口定义及示例；
- 短信触发时机、模板变量和失败处理；
- 联调环境地址、测试租户、测试账号及设备编码；
- 数据库迁移版本与前端构建版本。
