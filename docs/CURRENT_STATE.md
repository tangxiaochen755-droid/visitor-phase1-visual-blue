## 待处理与已知风险

- 每次 UI 修改必须做逐页视觉回归；仅检查 HTML/CSS 规则不足以证明页面正常。
- 线上 GitHub Pages 可能存在短暂缓存，发布后必须验证实际资源和页面。
- 历史修改曾出现黑白版与浅蓝版互相覆盖，后续必须遵守版本职责。
- 历史视觉改版曾因只做尺寸与可点击性验收而遗漏业务字段；后续 UI 修改必须增加“端、模块、字段、操作、状态、校验”业务语义回归，不得仅以视觉截图作为功能完整性证明。
- 后台 Remix Icon 线上 CSS 与 WOFF2 均返回 200 且文件哈希与本地一致，但字体图标仍存在客户端渲染不稳定风险；后续建议迁移内联 SVG。
- “企信通”供应商尚未冻结，不同供应商可能使用 `appId + SecretKey`、`appKey + appSecret` 或其他凭证组合；真实对接前必须以采购供应商官方文档为准。
