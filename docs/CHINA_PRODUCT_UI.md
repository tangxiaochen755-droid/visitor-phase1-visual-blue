# 国内产品 UI 默认规范

## 默认市场

除非需求明确指定海外市场或特殊风格，本项目所有产品默认面向中国大陆用户，优先采用微信小程序、企业微信、钉钉、飞书及国内主流移动组件库形成的常见信息密度、导航、表单、列表和反馈模式。

## 设计决策顺序

1. 明确用户进入页面的核心任务与高频操作。
2. 将控件标记为 P0 高频、P1 常用、P2 低频。
3. 对照至少三类国内同类产品的共同交互模式，不只比较视觉截图。
4. 先确认信息架构和操作路径，再确定字号、颜色、圆角和阴影。
5. 编制目标视口的首屏高度预算。
6. 用户确认方案后实施，并用真实页面和多状态截图验收。

## 移动端列表与筛选

- 搜索和高频状态筛选可以外露；日期、类型、部门、来源等低频条件默认进入 Bottom Sheet。
- 常驻筛选默认不超过两行，总高度宜控制在 80–100px；超过时必须说明业务原因。
- 状态超过四项时允许横向滚动，综合筛选入口固定在右侧，不随状态滚动。
- 次级筛选生效后必须通过小圆点、数量或摘要给出反馈。
- 不允许将 PC 多行筛选表单直接纵向搬到 430px 以内页面。
- 页面左右边距默认 16px；主要触控区不低于 44px。
- 常用字号采用 22/17/15/14/12px 层级；不使用 13px 作为分组标题。
- Bottom Sheet 默认不超过视口 60%，顶部圆角 12px，遮罩建议 rgba(0,0,0,.5)。

## 首屏验收

- 390×844 与 430×932 均需检查。
- 记录列表第一张卡片必须在首屏主要内容区完整可见；第二张应尽可能露出有效信息。
- 同时验证默认、有筛选、空状态、弹窗打开、长文字和最大数量状态。
- 检查横向溢出、安全区、键盘遮挡和底部导航遮挡。
